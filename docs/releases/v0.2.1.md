# ryzen-smu-cli v0.2.1

This patch release makes the PawnIO system-driver requirement explicit and
adds a verified clean-system package.

## Highlights

- Missing PawnIO installations now produce an actionable error with the
  official download URL and bundled-installer guidance.
- A new self-contained-with-PawnIO archive contains the unmodified official
  PawnIO 2.2.0 installer.
- Packaging pins the installer SHA-256 and requires a valid `namazso.eu`
  Authenticode signature before creating that archive.
- PawnIO installation is always interactive and administrator-approved. The
  application never silently installs a kernel driver.
- Installation, upgrade, removal, security, architecture, release, and
  third-party documentation now cover PawnIO correctly.

## Downloads

- `ryzen-smu-cli-v0.2.1-win-x64-self-contained-with-pawnio.zip`
  - includes the .NET 8 runtime and official PawnIO 2.2.0 installer;
  - recommended for a clean Windows installation;
  - run the installer interactively as an administrator before the first
    hardware command.
- `ryzen-smu-cli-v0.2.1-win-x64-self-contained.zip`
  - includes the .NET 8 runtime;
  - recommended when signed PawnIO is already installed.
- `ryzen-smu-cli-v0.2.1-win-x64-framework-dependent.zip`
  - smaller;
  - requires the .NET 8 x64 runtime and an existing PawnIO installation.
- `ryzen-smu-cli-v0.2.1-symbols.zip`
  - debugging symbols for crash analysis.
- `checksums-sha256.txt`
  - SHA-256 hashes for all four archives.

The PawnIO hardware modules used by ZenStates-Core are embedded in the
application. Only the system driver requires installation. Do not select the
unsigned unrestricted PawnIO edition.

Keep `inpoutx64.dll` beside `ryzen-smu-cli.exe`. Run hardware commands from an
Administrator PowerShell.
