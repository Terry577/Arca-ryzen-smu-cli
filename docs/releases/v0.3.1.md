# ryzen-smu-cli v0.3.1

This feature release adds a concise hardware information command.

## Highlights

- `--info` prints the detected CPU name, CPUID, architecture code name, model,
  package, CCD/CCX/core topology, motherboard, BIOS, CPU firmware revision,
  and SMU version.
- Hexadecimal identifiers use stable uppercase formatting suitable for
  comparing output between BIOS or firmware updates.
- Missing optional board or firmware values are reported as `N/A` rather than
  guessed.
- The command reuses the existing ZenStates-Core hardware session and does not
  initialize a second CPU probe.
- Automated tests enforce the complete ten-line output contract.
- The read-only hardware smoke-test script now includes `--info`.

## Usage

Run from an Administrator PowerShell:

```powershell
.\ryzen-smu-cli.exe --info
```

Example output:

```text
CPU        AMD Ryzen 7 9800X3D 8-Core Processor
CPUID      B40F40 (GraniteRidge)
Model      44
Package    FPX
Config     1 CCD / 1 CCX / 8 physical cores
MB Vendor  Micro-Star International Co., Ltd.
MB Model   MPG X870I EDGE TI EVO WIFI (MS-7E50)
BIOS       1.A32
Firmware   0B404035
SMU        98.83.0
```

`--info` is a read-only hardware operation. Like the other SMU commands, it
requires Windows, administrator privileges, and an installed signed PawnIO
driver.
